## 提示词：
提示  构建“Gummy Bears” - 一个单一的自包含HTML文件（仅依赖CDN上的three.js）：在白色桌子上的一小把半透明的软糖熊，你可以抓住、拉伸、挤压、扔和倾倒。  软糖熊 - 经典软糖熊轮廓：圆形头部带两个耳朵，短吻，丰满的身体，粗短的手臂和腿部，小型模压眼睛和鼻子 - 每个部分平滑融化到下一个部分 - 将身体构建为隐式表面（元球 / 行进立方体），而不是单独的球体 - 材质：真实的软糖果。半透明，具有透射和折射，颜色光吸收在厚实部分更深，光泽清漆带有锐利的亮点 - 颜色：樱桃红、橙色、柠檬黄、苹果绿、透明菠萝 - 每个熊下方柔和的有色阴影，由熊自身的颜色着色  物理效果（这是整个重点 - 必须感觉像果冻，而不是塑料） - 每只熊是一个软体：头部、耳朵、吻、身体、腹部、手和脚的质量点，通过体积保持的形状匹配连接在一起 - 四肢和脖子渲染为点之间的可拉伸链条，拉伸时变细 - 抓住任何部分并拉动：它像橡胶一样拉伸，熊的其余部分随之倾斜，松开时它会弹回并伴随阻尼摆动 - 向上拉头部：脖子拉伸，身体跟随，松开时熊会挤压并跳跃 - 向下按压头部：熊会像煎饼一样压扁，向侧面膨胀，然后弹回向上 - 扔一只熊：它飞翔，落地时挤压，弹跳并推开其他熊 - 熊之间会碰撞，绝不会穿过彼此 - 闲置的熊会进行小型随机跳跃，伴随挤压和拉伸 - “倾倒更多熊”从上方掉下一把，落入摇晃、抖动的堆中  用户界面 - 编辑风格的产品页面风格，白色背景。大型斜体衬线标题“Gummy / Bears.”，一个简短的副标题，右侧一个最小化卡片带有口味样本，一个摇摆滑块，实时“拉伸”和“弹跳”读数，以及一个“倾倒更多熊”按钮 - 一个微妙的圆形光标，在抓取时会增大 - ACES色调映射，环境反射，柔和主光和背光。平滑60fps；网页上要用中文哦

## 玩法

- **拿起并拉伸**：拖拽任意部位，软糖熊会像橡皮一样拉长，身体随之倾斜，松手带阻尼回弹。
- **压扁**：按住头部向下拖，熊会压成煎饼、向两侧鼓起，松手后弹回。
- **扔出去**：快速拖拽后松手，熊会飞出去、落地挤压、弹跳并撞开其他熊。
- **再倒一把**：点击“倾倒更多熊”，新的软糖熊会从上方落进摇晃的堆里。

## 页面

- 白色编辑风产品页，大号斜体衬线标题 **Gummy / Bears.**
- 右侧口味卡：樱桃红、香橙、柠檬黄、苹果绿、透明菠萝
- 摇摆滑块，以及实时的“拉伸”和“弹跳”读数
- 圆形光标在抓取时放大；桌面与手机均有适配
- ACES 色调映射、PMREM 环境反射、柔和主光与背光

## 技术

- `index.html` 为单一自包含文件，运行时仅依赖 CDN 上的 [three.js](https://threejs.org/)
- 平滑隐式表面 + Marching Cubes 构建连续软糖身体
- 软体粒子、形状匹配、拉伸细化、粒子碰撞与地面摩擦
- 程序化厚薄遮罩控制颜色吸收，半透明材质带有屏幕空间折射
- 按熊数量和实时帧率自适应渲染分辨率，保持 60fps 交互
